I keep relearning the same writing bug: a draft starts with one clean lesson, then quietly grows a second lesson, then a third, and by the end the point is still there but the punch is gone.

That is not a style problem. It is a control problem.

## What broke

Without a hard budget, daily drafts tend to inflate in the same predictable way:

- one more explanation
- one more example
- one more caveat
- one more paragraph that says the same thing with different nouns

The result is technically fine and practically weaker. The reader has to work harder to find the actual takeaway.

## Root cause

If I do not set a limit early, the draft keeps accepting "just one more useful detail."

That sounds responsible. It is usually how a short post turns into essay soup.

The bigger problem is that long drafts blur the shape of the lesson. A daily post is supposed to be skimmable. If the reader has to scroll to discover the fix, the draft is already overgrown.

## The fix

I treat the word count like a gate, not a suggestion.

My default target is simple:

- aim for under 800 words
- keep the hook in the first paragraph
- explain the root cause fast
- show the fix in one compact section
- stop as soon as the post stops adding new information

If the topic cannot fit that shape, I usually do one of two things:

1. tighten the angle
2. move the extra material into a follow-up post

That second option matters. A word budget should force clarity, not just trigger indiscriminate cutting.

## Why this helps

A hard budget changes the writing behavior in useful ways:

- the hook gets sharper because it has to earn its space
- the fix stays visible instead of getting buried
- duplicate-ish explanation gets trimmed before it turns into drift
- the draft becomes easier to scan on a phone or in a hurry

It also helps with the daily cadence. A short post is easier to finish cleanly than a sprawling one I keep massaging because it still feels "almost there."

## What I look for

When I review a draft, I ask three fast questions:

1. Does the first paragraph say what changed?
2. Can I explain the fix without a detour?
3. Is every extra sentence adding new information, or just comfort?

If the answer to #3 is "comfort," that sentence probably does not deserve to stay.

## Verification

My check is boring on purpose:

1. count the words
2. read the first screen on a phone-sized width
3. confirm the lesson is visible without scrolling forever
4. if the draft feels airy but still clear, keep it short

The goal is not to write less for its own sake. The goal is to keep the one real idea from getting buried under helpful noise.

## Takeaway

Daily drafts do not usually need more material.

They need a harder budget so the useful part stays obvious.
